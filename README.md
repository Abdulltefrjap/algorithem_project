## نظرة عامة

نظام **Kanban** لإدارة المشاريع والمهام يطبّق الخوارزميات عملياً:
- **Merge Sort & Quick Sort** لترتيب المهام (بدون `sort()` المدمجة)
- **Divide & Conquer** لحساب مدة المشروع عودياً
- تقرير يعرض **نسبة الإنجاز** و**المهام المنجزة لكل عضو**

## التشغيل السريع

### Windows
انقر مرتين على `start.bat`

### يدوياً
```bash
cd backend
pip install -r requirements.txt
python seed_data.py --reset
uvicorn app.main:app --reload --port 8000

cd frontend
npm install
npm run dev
```
